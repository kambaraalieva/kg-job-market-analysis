# Рынок вакансий Кыргызстана: что предлагают работодатели и что они скрывают

Анализ 12 646 онлайн-вакансий с hh.kg и lalafo.kg (февраль–март 2024): от чего зависит
предлагаемая зарплата и почему половина работодателей её не указывает.

**Начните с [`notebooks/00_summary.ipynb`](notebooks/00_summary.ipynb)**: там все итоги, графики и рекомендации.

## Главные выводы

1. **52% вакансий скрывают зарплату.** Чаще всего это вакансии для опытных и вакансии банков (94%).
2. **Опыт 3–6 лет даёт +54%** к зарплате вакансий без опыта.
3. **hh и lalafo это два разных рынка:** hh платит на 14% больше, в IT почти втрое больше.
4. **Профессия важнее сферы:** от ~18 тыс. сом (охранник) до ~93 тыс. (технолог).
5. **Диплом почти не влияет на зарплату:** около +1% внутри одной сферы.
6. **Разрыв по полу в основном объясняется профессиями:** −18% в целом, −6% внутри профессии.
7. **Зарплаты круглые:** 88% сумм, кратных тысяче, заканчиваются на 0 000 или 5 000.

Типичная зарплата в объявлениях около 35–40 тыс. сом; в Бишкеке примерно на 10% выше
официальной средней по данным Нацстаткома.

## Динамика 2024–2026 (ноутбук 08)

- **Та же вакансия подорожала примерно на 31%** с I квартала 2024 до конца 2026 (с поправкой на профессию,
  опыт, город и валюту); простая медиана показывает только +17%, потому что из рынка уходят долларовые IT-вакансии.
- Официальная средняя зарплата за то же время выросла на 61% (34 046 → 54 864 сом).
- Продажи и маркетинг +40% (50 000 → 70 000 сом), IT почти без роста; сфера услуг ориентировочно +43%.
- Доля скрытых зарплат в Telegram упала с 53% до 32%.

## Данные

- **Источник:** открытый датасет School of Data Kyrgyzstan «Кыргызстан в цифрах»,
  [datakyrgyzstan.opendata.kg/vacancy](https://datakyrgyzstan.opendata.kg/vacancy).
  Вакансии собраны с hh.kg и lalafo.kg.
- **Исходный файл:** `data/raw/vacancy.xlsx`, 13 349 вакансий, 22 колонки.
- **После очистки:** `data/processed/vacancies_clean.csv`, 12 646 вакансий, из них 5 840 с правдоподобной зарплатой.
- **Официальная статистика для сравнения:** Нацстатком КР через economist.kg (ссылки в `00_summary`).
- **Курсы валют:** НБКР на 14.03.2024 (для 2026: на 30.06.2026).
- **Данные Telegram 2024–2026:** 65 511 постов каналов @codifynews (офисные, IT, продажи; с января 2024) и
  @kgworkzone (сфера услуг, общепит, торговля; с ноября 2025), собраны через официальный Telegram API.
  После разбора и удаления повторов **32 010 вакансий**, из них 18 342 с зарплатой (ноутбук `07_telegram_2026`,
  разбор свободного текста в `src/telegram_parse.py`). Телефоны и @username в текстах скрыты.
- **Мастер-датасет 2024–2026:** `data/processed/vacancies_2024_2026_master.xlsx` (для чтения) и `.csv.gz` (для кода):
  53 916 вакансий, 44 колонки, собран заново из исходных файлов по единым правилам (`src/dataset.py`, ноутбук
  `09_master_dataset`): даты во времени Бишкека, неуказанный опыт и город остаются пустыми, полный текст объявления
  и вся дополнительная информация сохранены. В Excel есть листы «словарь», «правила» и «журнал».
- **Объединённый файл для моделей:** `data/processed/vacancies_2024_2026.csv`, **44 656 вакансий** с точными датами
  публикации, без пропущенных месяцев с января 2024 по октябрь 2026; колонки `source`, `year`, `period`
  отличают источники и годы.
- **Исправление источника:** профессия «Менеджер по продажам» в справочнике источника была отнесена к сфере
  «Спортивные клубы, фитнес, салоны красоты»; перенесена в «Продажи, обслуживание клиентов».

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Порядок запуска: **02 → 03 → 04 → 05 → 06 → 00**, затем **07 → 08 → 09** (данные 2024–2026). Ноутбук 02 создаёт `vacancies_clean.csv`,
остальные строят графики в `reports/figures`.

## Словарь данных (`vacancies_clean.csv`)

| Колонка | Описание |
|---|---|
| `id`, `link` | идентификатор и ссылка на объявление |
| `name`, `company` | название вакансии и работодатель (работодатель указан почти только на hh) |
| `category`, `sub_category` | сфера (27 значений) и профессия (169 значений) |
| `source` | сайт: `headhunter` или `lalafo` |
| `published`, `pub_month` | дата и месяц публикации |
| `area`, `city` | населённый пункт; группа Бишкек / Ош / Регионы |
| `experience`, `experience_start` | требуемый опыт: группа и нижняя граница в годах (0, 1, 3, 6) |
| `education` | требование к образованию из текста: высшее / среднее специальное / не указано |
| `gender_req` | требование к полу из текста: женщины / мужчины / оба указаны / не указано |
| `schedule` | график из текста (5/2, 6/1, 2/2…) |
| `remote`, `commission`, `kyrgyz_text` | удалённая работа, оплата с процентами или бонусами, текст на кыргызском |
| `skills`, `n_skills` | ключевые навыки (почти только hh) и их число |
| `requirements`, `responsibilities`, `text_len` | тексты объявления и длина требований |
| `compensation_from`, `compensation_to`, `compensation_currency` | исходная зарплата из объявления |
| `salary_type` | формат: range / from / to / hidden |
| `pay_period` | период ставки после пересчёта: month / day / week / hour |
| `salary_outlier` | зарплата признана неправдоподобной и удалена (вакансия сохранена) |
| `salary_hidden` | работодатель не указал зарплату |
| `has_salary` | есть правдоподобная зарплата |
| `salary_kgs` | **итоговая зарплата, сом в месяц** |

## Ограничения

- Это предложения работодателей, а не фактические зарплаты.
- Только два сайта; 83% объявлений из Бишкека, данных по регионам мало.
- Ноутбуки 01–06: снимок начала 2024 года; динамика 2024–2026 в основном по одному каналу (codifynews).
- Текстовые правила (дневная ставка, образование, пол) вручную не проверялись;
  проверка устойчивости показывает, что главные выводы от этих допущений не зависят.
- Все различия это связи, а не причины.
